# Wainwright Planner 🥾

A modern interactive planner and progress tracker for completing all 214 Wainwright fells in the Lake District.

Built with Next.js, React Leaflet, TypeScript, Tailwind CSS, and Supabase.

---

## ✨ Features

- 🗺️ Interactive Lake District map
- ✅ Track completed Wainwrights
- ⭐ Mark priority fells
- 📍 Plan custom walking routes
- 💾 Save routes locally
- ☁️ Supabase sync support
- 📊 Progress dashboard & stats
- 🔍 Search, filter & sort fells
- 🌦️ Weather integration ready (COMING SOON)
- 📱 Responsive modern UI

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/wainwright-planner.git
```

### 2. Navigate into the project

```bash
cd wainwright-planner
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create environment variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
NEXT_PUBLIC_ORS_API_KEY=your_openrouteservice_key
```

---

## ▶️ Run the development server

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
